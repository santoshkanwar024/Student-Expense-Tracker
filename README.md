# Student Expense Tracker

## Overview
Student Expense Tracker is a console-based application developed in C++ to help students manage and track their expenses.

## Features
- Add Expense
- View Expenses
- Edit Expense
- Delete Expense
- Total Expense Calculation
- Category-wise Expense Report
- CSV File Storage
- Console-based Menu Driven Application

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- STL (Vector, Map, Stringstream)

## How to Run
Compile:
g++ main.cpp -o expense

Run:
bash
./expense
