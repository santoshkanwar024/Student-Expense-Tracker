# Student Expense Tracker

## Overview
Student Expense Tracker is a console-based application developed in C++ to help students manage and track their expenses.

## Features
- Add Expense
- View Expenses
- Delete Expense
- Total Expense Calculation
- Category Wise Report
- File Based Data Storage
- Load Data From File

## Technologies Used
- C++
- Object Oriented Programming (OOP)
- STL Vector
- STL Map
- File Handling

## How to Run
Compile:
g++ main.cpp -o expense

Run:
bash
./expense
