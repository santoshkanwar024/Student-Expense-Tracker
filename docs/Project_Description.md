# Project Description

## Problem Statement
Many students spend money daily but do not keep track of their expenses. As a result, they often do not know where their money is being spent.

## Objective
The objective of this project is to develop a simple console-based application that helps students record, manage, and analyze their expenses.

## Features Implemented
1. Add Expense
2. View Expenses
3. Edit Expense
4. Delete Expense
5. Calculate Total Expenses
6. Category-wise Expense Report
7. Store data in CSV format
8. Load data automatically when the program starts

## Technologies Used
- C++
- Object Oriented Programming
- STL Vector
- STL Map
- File Handling

## Data Storage
Expense records are stored in a text file named `expense.txt`.
