# Project Description

## Problem Statement
Many students spend money daily but do not keep track of their expenses. As a result, they often do not know where their money is being spent, making it difficult to manage their monthly budget.

## Objective
The objective of this project is to develop a simple console-based application that helps students record, manage, search, and analyze their daily expenses efficiently.

## Features Implemented
1. Add Expense (Automatic Expense ID Generation)
2. View Expenses
3. Edit Expense
4. Delete Expense
5. Calculate Total Expenses
6. Category-wise Expense Report
7. Search Expenses by Category
8. Store data in CSV format
9. Load data automatically when the program starts

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- STL Vector
- STL Map
- String Stream (`stringstream`)
- File Handling
- I/O Manipulators (`iomanip`)

## Data Storage
Expense records are stored in a CSV file named `expense.csv`. The application automatically loads existing records when it starts and saves all changes to the CSV file.
